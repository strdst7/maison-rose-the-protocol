# The Rose Protocol

The Rose Protocol is a browser-based cybersecurity quiz for people learning practical digital self-defense.

## About

Answer 12 questions about passwords, phishing, account security, and privacy. Each answer reveals an explanation and a practical security habit. Results include your score, rank, and suggestions based on missed questions.

The app runs in your browser. It needs no account or backend. The share action copies your result text to the clipboard.

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Build

```sh
npm run build
npm run preview
```

The production build is written to `dist/`. Deploy that directory to a static web host.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
